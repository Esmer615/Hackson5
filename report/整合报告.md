# 整合报告

## 项目概述

Hackson5 Knowledge Integration Agent 已完成从教材上传到知识整合展示的端到端闭环。系统面向教师备课场景，支持上传多本教材，自动解析章节、抽取知识图谱、合并相似知识点、构建 RAG 检索索引，并通过可视化工作台展示结果。

## 已实现能力

- 教材接入：支持 PDF、Markdown、TXT 上传，保存教材文件和元数据。
- 处理模式：提供 Demo Mode 与 Quality Mode，平衡演示速度和处理深度。
- LangGraph 流水线：按 parse、graph、integrate、rag、report 五阶段执行。
- AI 抽取：DeepSeek 可用时调用模型；缺少 `DEEPSEEK_API_KEY` 时启用确定性 fallback。
- 知识图谱：生成节点、关系边、页码、频次、分类和来源信息。
- RAG 问答：对章节内容进行 chunk 切分，返回回答、引用和源文本块。
- 教师反馈：记录教师对整合决策的反馈，并可将决策覆盖为保留。
- 前端展示：使用 ECharts 展示知识图谱，提供上传、状态、问答、反馈和报告面板。

## 系统流程

```text
上传教材 -> 解析章节 -> 抽取知识点 -> 跨教材整合 -> 构建 RAG 索引 -> 生成报告 -> 教师审阅反馈
```

教师可以在工作台中完成全部操作：上传教材、选择模式、运行流水线、查看图谱、询问问题、检查引用、提交反馈并查看整合报告。

## 关键设计亮点

1. 可演示性：Demo Mode 与 fallback 机制保证在无外部模型凭据时仍能跑通流程。
2. 可追溯性：知识节点保留页码和来源；RAG 回答返回 citations 与 source_chunks。
3. 可控制性：教师反馈能够覆盖 AI 整合决策，避免黑箱式自动合并。
4. 可扩展性：Django app 按 api、schemas、services、models 分层，LangGraph 节点可继续拆分或替换。
5. 可部署性：本地 SQLite 方便开发，Railway PostgreSQL 支持生产部署，Vercel 承载前端。

## API 摘要

| 能力 | API |
| --- | --- |
| 上传教材 | `POST /api/textbooks/upload` |
| 运行流水线 | `POST /api/pipeline/run` |
| 查询状态 | `GET /api/pipeline/status` |
| 获取图谱 | `GET /api/graph` |
| 构建 RAG 索引 | `POST /api/rag/index` |
| RAG 问答 | `POST /api/rag/query` |
| 教师反馈 | `POST /api/teacher/chat` |
| 获取报告 | `GET /api/report` |

## 数据模型摘要

核心数据包括 `Textbook`、`Chapter`、`KnowledgeNode`、`KnowledgeEdge`、`IntegrationDecision`、`RagChunk`、`ConversationMessage` 和 `PipelineRun`。这些模型覆盖教材文件、章节正文、知识结构、整合动作、检索索引、教师对话和流水线进度。

## 部署与运行

- 前端生产地址：`https://hackson5.vercel.app`
- 后端生产地址：`https://hackson5-production.up.railway.app`
- 本地后端：`cd backend && uv run python manage.py runserver`
- 本地前端：`cd frontend && pnpm dev`
- 后端测试：`cd backend && uv run pytest`
- 前端检查：`cd frontend && pnpm lint && pnpm format:check && pnpm build`

## 风险与注意事项

- PDF 与上传教材可能包含版权或敏感内容，不应提交到 Git，也不应上传未经授权的教材。
- DeepSeek fallback 适合演示和测试，不等同于高质量模型抽取结果。
- 当前流水线以同步方式执行，适合黑客松演示；生产大文件处理可改为异步任务队列。
- RAG 向量为轻量实现，后续可替换为专业 embedding 模型和向量数据库。

## 后续优化方向

1. 增加后台异步任务和进度推送，提升大文件处理体验。
2. 引入更强的 embedding 与重排序模型，提高 RAG 命中质量。
3. 增加教师人工确认界面，批量审核 merge/keep/remove 决策。
4. 支持图谱导出、课程大纲生成和教学活动推荐。
5. 完善权限、文件清理和上传大小控制，增强生产安全性。
